What is Python?

print, comments, maths

A program is a recipe: a list of instructions the computer follows from top to bottom, one line at a time. Python is a language for writing those instructions in words that read almost like English.

The first instruction everyone learns is print. Whatever you put inside the brackets appears on the screen. Text goes inside quotes so Python knows to show it exactly as written. Leave the quotes off and Python works out the maths instead.

A line that starts with # is a comment. Python skips it. Comments are notes for the humans who read your code later, including you.

What each line does
print("Namaste, Python!")

Shows the text on the screen. The quotes tell Python this is text, so it prints it exactly as written.

print(7 + 3)

No quotes, so Python does the maths first and prints the answer, 10.

print(7 / 2)

A single slash is normal division. It gives 3.5, a number with a decimal point.

print(2 ** 3)

Two stars means power: 2 multiplied by itself 3 times, which is 8. The text after # is a comment, and Python ignores it.

print(17 // 5)

Double slash divides and throws away the remainder. 5 goes into 17 three whole times, so the answer is 3.

print(17 % 5)

The percent sign keeps only the remainder. 17 is 15 + 2, so it prints 2. Useful to check if a number is even.

print((2 + 3) * 4)

Brackets are worked out first, so 2 + 3 becomes 5, then 5 × 4 gives 20. Without brackets it would be 14.

Remember

  • Quotes mean text. No quotes means Python calculates.
  • // keeps the whole part of a division, % keeps the remainder.
  • Python follows BODMAS: brackets, powers, multiply and divide, then add and subtract.

Variables

boxes that remember

An answer that is only printed is gone the moment it appears. To remember a value, put it in a variable: a labelled box. The name goes on the label and the value goes inside.

In Python, = does not mean "equals". It means "put this in the box". So score = score + 5 is not impossible maths: read it right to left. Take what is in score, add 5, and put the result back in score.

Names can use letters, numbers and underscores, cannot start with a number and cannot contain spaces. Python is case sensitive, so age and Age are two different boxes. Pick names that say what is inside, like monthly_salary.

What each line does
price = 250

Creates a box called price and puts 250 inside. The = means store, not equals.

quantity = 3
discount = 100

Two more boxes, each with a clear name, so anyone reading knows what the numbers mean.

total = price * quantity - discount

Python opens the boxes, works out 250 × 3 − 100 = 650, and stores the answer in a new box called total.

print(total)

Shows what is inside total: 650.

score = 10
score = score + 5

Read the second line right to left: take what is in score (10), add 5, and put 15 back into score.

score += 5

A shortcut that means exactly the same as score = score + 5. Now score holds 20.

Remember

  • One = stores a value in a variable.
  • Change the price in one place and every calculation that uses it updates.
  • A NameError usually means a typo in a variable name.

03

Data types

int, float, str, bool

Every value in Python has a type, and the type decides what you can do with it. Whole numbers are int, numbers with a decimal point are float, text is str (short for string), and True or False is bool.

This is why "10" + "5" gives "105". The quotes made them text, and adding text joins it together. Convert first with int(), float() or str() and the maths works again.

Ask Python for any value's type with type(). Notice that dividing always gives a float, even when the answer is a whole number.

What each line does
print(type(5))

type() tells you what kind of value something is. 5 is a whole number, so it is an int.

print(type(3.14))

It has a decimal point, so it is a float.

print(type("hello"))

Anything inside quotes is text, which Python calls a str (string).

print(type(True))

True and False are their own type, bool, used for yes-or-no answers.

print("10" + "5")

Both are text because of the quotes, and + on text glues them together. That is why you get 105.

print(int("10") + int("5"))

int() turns the text into real numbers first, so now + does maths and gives 15.

print(10 / 2)

Division always gives a float, so even a whole answer prints as 5.0.

print(0.1 + 0.2)

Computers store decimals as tiny approximations, so the answer is a hair off 0.3. Use round() when you show money.

Remember

  • Quotes turn anything into text, even numbers.
  • Use int() or float() before doing maths on text that holds a number.
  • 0.1 + 0.2 being slightly off is normal in every language. Use round() to tidy it.

Working with text

f-strings, indexing, slicing

Text is a row of characters, and each one has a position. Python counts positions from 0, so the first letter is at position 0. A negative position counts from the end.

A slice like name[1:3] takes characters from position 1 up to, but not including, position 3. Strings also come with built-in tools such as upper(), replace() and split().

An f-string is the cleanest way to put values inside a sentence. Put an f before the quotes and write variable names inside curly brackets.

What each line does
name = "Priya"
city = "Pune"

Two text variables we will use below.

print(f"{name} lives in {city}")

The f before the quotes makes it an f-string. Python swaps {name} and {city} for their values.

print(len(name))

len() counts the characters. Priya has 5 letters.

print(name[0])

Square brackets pick one character by position. Counting starts at 0, so [0] is the first letter, P.

print(name[-1])

Negative positions count from the end. [-1] is always the last character, a.

print(name[1:3])

A slice: from position 1 up to, but not including, 3. That gives the letters at 1 and 2, ri.

print(name.upper())

upper() returns a capital-letter copy. The original name is not changed.

print("chai,samosa,vada pav".split(","))

split() cuts the text wherever it finds a comma and gives back a list of the pieces.

Remember

  • Counting starts at 0, not 1.
  • In a slice the end position is not included.
  • f-strings beat joining text with + because they convert numbers for you.

Talking to your program

input()

input() pauses the program, shows a question, and waits for the user to type something and press Enter. Whatever they type comes back to you as text.

That is the classic beginner trap. If someone types 20 for their age, Python hands you the text "20", not the number 20. Wrap it in int() or float() before doing any maths.

What each line does
bill = float(input("Bill amount: "))

input() shows the question and waits for the user. What they type comes back as text, so float() turns it into a number with decimals.

tip_percent = int(input("Tip %: "))

Same idea, but int() because a tip percent is a whole number.

tip = bill * tip_percent / 100

Works out the percentage: 850 × 10 ÷ 100 = 85.0.

print(f"Tip: Rs {tip}")

An f-string puts the tip inside the sentence.

print(f"Total: Rs {bill + tip}")

You can even do maths inside the curly brackets. 850 + 85 = 935.

Remember

  • input() always returns text.
  • Convert right away: int(input(...)).
  • The question inside the brackets is what the user sees.

06

True or False

comparisons, and, or, not

A comparison asks Python a yes-or-no question and the answer is always True or False. The operators are == (equal), != (not equal), <, >, <= and >=.

Watch the difference: one = stores a value, two == compares two values. Mixing them up is one of the most common beginner errors.

Combine questions with and (both must be true), or (at least one is true) and not (flips the answer).

What each line does
marks = 72

The value we will ask questions about.

print(marks >= 35)

Is 72 greater than or equal to 35? Yes, so True.

print(marks == 100)

Two equals signs compare. 72 is not 100, so False.

print(marks != 100)

!= means not equal. 72 is not 100, so True.

print(marks > 60 and marks < 80)

and needs both sides to be True. 72 is above 60 and below 80, so True.

print(marks < 35 or marks > 90)

or needs at least one side to be True. Neither is, so False.

print(not marks >= 35)

not flips the answer. marks >= 35 is True, so not makes it False.

print(30 < marks < 80)

Python lets you chain comparisons like in maths: is 72 between 30 and 80? True.

Remember

  • One = stores, two == compares.
  • and needs both sides true, or needs one.
  • Text comparisons are case sensitive: "Yes" == "yes" is False.

Decisions with if

if, elif, else

if lets your program choose. If the condition is True, the indented lines underneath run. If not, Python skips them. else catches everything that did not match.

When there are more than two roads, use elif. Python checks each condition from the top and runs only the first one that is True, so put the strictest check first.

Indentation (four spaces) is not decoration in Python. It is how Python knows which lines belong to the if.

What each line does
if marks >= 90:

Asks the first question. It ends with a colon, and the indented line below only runs if the answer is True. 72 is not 90 or more, so Python skips it.

elif marks >= 60:

elif means else if. Python checks this only because the first one was False. 72 is 60 or more, so this branch runs and prints Grade B.

elif marks >= 35:

Skipped. Once one branch has run, Python ignores the rest of the chain.

else:

Catches anything that matched none of the questions above.

if number % 2 == 0:

% 2 gives the remainder after dividing by 2. If it is 0 the number is even. 7 leaves 1, so the else runs and prints odd.

Remember

  • Only the first True branch runs.
  • Order matters: check 90 before 60.
  • A missing colon or wrong indentation is a SyntaxError.

Lists

many values in one box

A list holds many values in one variable, written inside square brackets. Positions start at 0, exactly like text, and -1 is the last item.

Unlike text, lists can change. append() adds to the end, you can replace an item by its position, and slicing gives you part of the list.

Python has built-ins that work on whole lists: len(), sum(), max(), min() and sorted(). Together they turn a week of sales into a report in a few lines.

What each line does
sales = [120, 95, 140, 80, 160]

One variable holding five values, inside square brackets, separated by commas.

print(sales[0])

Position 0 is the first item: 120.

print(sales[-1])

Position -1 is the last item: 160.

print(sales[1:3])

A slice gives a smaller list: positions 1 and 2, so [95, 140].

sales.append(110)

append() adds a new item to the end. The list now has 6 values.

sales[1] = 100

Lists can change. This replaces the item at position 1 (95) with 100.

print("Total:", sum(sales))

sum() adds every number in the list.

print("Best day:", max(sales))

max() finds the biggest value.

print("Average:", round(sum(sales) / len(sales), 1))

Total divided by how many items is the average. round(..., 1) keeps one decimal place.

Remember

  • First item is [0], last is [-1].
  • Lists can grow and change; text cannot.
  • sum(x) / len(x) is the average.

Loops

for, range, while

A loop repeats work so you don't have to. A for loop goes through every item in a list (or every letter in text) and runs the indented lines once for each.

range(1, 4) gives the numbers 1, 2 and 3. The end number is not included, just like slicing. A very common pattern is to start a total at 0 and add to it inside the loop.

A while loop repeats as long as a condition is True. Make sure something inside the loop changes, or it never stops. break leaves a loop early and continue skips to the next round.

What each line does
for lap in range(1, 4):

range(1, 4) makes the numbers 1, 2, 3 (the 4 is not included). Each time round, lap holds the next number.

    print("Lap", lap)

The indented line is the loop's body. It runs once for every number.

total = 0

Start a running total at zero before the loop.

for amount in [250, 120, 80]:
    total += amount

Goes through each amount and adds it to total: 0 + 250 + 120 + 80 = 450.

while countdown > 0:

A while loop keeps going as long as the condition is True.

    countdown -= 1

Takes 1 away each time. Without this line countdown would stay at 3 and the loop would never stop.

print("Go!")

Not indented, so it runs once, after the loop has finished.

Remember

  • for is for "each item", while is for "until".
  • range(a, b) stops before b.
  • enumerate() gives you the position and the value together.

Functions

def, parameters, return

A function is a recipe with a name. You write it once with def and use it as many times as you like. Inputs go in the brackets (parameters) and return sends the answer back.

print only shows a value on screen. return hands the value back so you can store it or use it in more maths. Most functions should return.

A parameter can have a default value that is used when you leave it out. Variables created inside a function stay inside it; the rest of the program cannot see them.

What each line does
def add_gst(price, rate=18):

def creates a function called add_gst. It takes a price and a rate. rate=18 is a default, used when you don't give one.

    return price + price * rate / 100

Works out the price plus GST and sends the answer back to whoever called the function.

print(add_gst(1000))

Calls the function with only a price, so rate uses the default 18. 1000 + 180 = 1180.0.

print(add_gst(1000, 5))

This time we pass 5, which replaces the default. 1000 + 50 = 1050.0.

def take_home(salary, tax_percent):

A second function with two inputs.

    tax = salary * tax_percent / 100

tax only exists inside the function. The rest of the program cannot see it.

pay = take_home(50000, 10)

The returned value, 45000.0, is stored in pay so we can use it later.

Remember

  • Write it once with def, call it many times.
  • return gives a value back; print only shows it.
  • Defaults make an argument optional.

Dictionaries and tuples

look things up by name

A dictionary stores pairs: a key and its value, like a word and its meaning. Instead of asking for position 0, you ask for a name, such as menu["chai"].

Asking for a key that is not there causes a KeyError. .get() is the safe way: it returns a default you choose instead of crashing. .items() lets you loop through keys and values together.

A tuple is a list that cannot change, written with round brackets. Use it for values that belong together and should stay fixed, like a map coordinate.

What each line does
menu = {"chai": 15, "samosa": 20, "vada pav": 25}

A dictionary in curly brackets. Each item is a key, a colon, then its value.

print(menu["chai"])

Look up by name instead of position. The value for chai is 15.

print(menu.get("dosa", "not on the menu"))

dosa is not a key yet. menu["dosa"] would crash with KeyError, but .get() returns the default you gave instead.

menu["dosa"] = 60

Assigning to a new key adds it to the dictionary.

for item, price in menu.items():

.items() gives each key and value together, so the loop can print both.

hyderabad = (17.38, 78.48)

A tuple uses round brackets. Like a list, but it cannot be changed after you create it.

print(hyderabad[0])

Tuples use positions just like lists. [0] is the latitude.

Remember

  • Dictionaries look up by key, lists by position.
  • Use .get(key, default) when a key might be missing.
  • Tuples cannot be changed after you create them.

When things go wrong

tracebacks, try and except

Errors are not failure. A traceback tells you exactly what went wrong and where. Read the last line first: it names the error type and gives a short reason.

The ones you will meet most are NameError (typo in a name), TypeError (mixing types like text + number), ValueError (int("abc")), IndexError (position past the end) and SyntaxError (missing colon, bracket or quote).

try and except let your program handle an error calmly instead of crashing. Put the risky line in try and the backup plan in except.

What each line does
try:

Python tries the indented lines below. If one causes an error, it jumps to the matching except instead of crashing.

    age = int("twenty")

int() cannot turn the word "twenty" into a number, so it raises a ValueError.

except ValueError:

Catches exactly that error and runs the friendly message instead.

marks = [80, 92, 75]

A list with 3 items, at positions 0, 1 and 2.

    print(marks[3])

Position 3 does not exist, so this raises an IndexError.

except IndexError:

Catches it and explains the problem using len(marks).

Remember

  • Read the last line of the traceback first.
  • Catch a specific error type, not every error.
  • Printing values in the middle of your code is the simplest debugger.

Build a real program

a quiz game

Everything comes together here: variables keep the score, a list of dictionaries holds the questions, a loop asks each one, input() takes the answer and if checks it.

Once it works, make it yours: add your own questions, give a grade at the end, or let the player try again.

What each line does
questions = [ {...}, {...} ]

A list of dictionaries. Each dictionary holds one question (q) and its answer (a).

score = 0

The player starts with no points.

for item in questions:

Goes through the questions one at a time. item is the current dictionary.

    answer = input(item["q"]).strip().lower()

Asks the question. strip() removes extra spaces and lower() makes Delhi and delhi count the same.

    if answer == item["a"]:

Compares the player's answer with the correct one.

        score += 1

Adds a point only for a right answer.

print(f"You scored {score}/{len(questions)}")

After the loop, shows the final score out of the number of questions.

Remember

  • Plan the data first, then the loop.
  • .strip().lower() forgives extra spaces and capitals.
  • Build one small piece, run it, then add the next.

Libraries

import superpowers

A library is code someone else already wrote and tested, ready for you to use. You bring it into your program with import. Python ships with many (math, random, datetime), and the data world runs on two more: NumPy for fast maths on numbers and Pandas for tables.

By convention NumPy is imported as np and Pandas as pd. Google Colab and Kaggle notebooks already have both installed; on your own computer you install them once with pip install numpy pandas.

What each line does
import math

Brings in Python's built-in maths library so you can use its tools.

import numpy as np

Brings in NumPy and gives it the short name np. Everyone uses this name.

import pandas as pd

Brings in Pandas with the short name pd.

print(math.sqrt(144))

Use a library's tool with libraryname.tool. sqrt gives the square root, 12.0.

print(round(1999 * 0.18, 2))

18% GST on Rs 1999, rounded to 2 decimal places for money.

print(math.ceil(4.2))

ceil always rounds up, so 4.2 becomes 5.

print(np.array([1, 2, 3]) * 10)

A first taste of NumPy: every number in the array is multiplied by 10.

Remember

  • import once at the top of your file.
  • np and pd are the names everyone uses.
  • Colab and Kaggle need no installation.

Files

data that survives

Variables vanish when the program ends. Files survive. open() with "w" writes a new file, "a" adds to the end, and no mode at all reads it.

The w trap: opening an existing file with "w" wipes it before writing. Use "a" when you want to keep what is there.

with open(...) as f: closes the file for you when the block ends. CSV (comma-separated values) is the plain-text format almost all data comes in: one row per line, columns split by commas.

What each line does
with open("chai.csv", "w") as f:

Opens (or creates) the file for writing. "w" wipes anything already in it. with closes the file automatically at the end.

    f.write("day,cups\n")

Writes one line. \n means new line, so the next write starts on its own row.

with open("chai.csv", "a") as f:

"a" means append: add to the end and keep what is already there.

with open("chai.csv") as f:

No mode means read.

    print(f.read())

read() gives back the whole file as text, so you see all three rows.

Remember

  • "w" overwrites, "a" appends.
  • Always use with so the file is closed.
  • A CSV is just text with commas.

NumPy

maths on whole lists

Multiply a Python list by 2 and it repeats the list. Multiply a NumPy array by 2 and every number doubles. That is the whole idea: one operation on every item at once, with no loop, and much faster on big data.

Arrays come with statistics built in (mean(), max(), sum()). You can also ask a yes-or-no question of every item at once and use the answer to filter, like "which innings were 50 or more?"

What each line does
prices = [100, 250, 80]

A normal Python list.

print(prices * 2)

Multiplying a list repeats it, which is almost never what you want for data.

print(np.array(prices) * 2)

Turn it into a NumPy array and * 2 doubles every number instead.

runs = np.array([...])

A batter's last 10 innings as an array.

print("Average:", runs.mean())

Arrays have statistics built in. mean() is the average, 41.8.

print(runs >= 50)

Asks the question of every innings at once and gives back True or False for each one.

print("Fifties:", runs[runs >= 50])

Putting that True/False array inside the brackets keeps only the True items: the fifties and hundreds.

Remember

  • A list repeats, an array calculates.
  • arr[arr >= 50] keeps only the matching items.
  • Arrays can be 2D tables: arr.shape tells you rows and columns.

Pandas

Excel inside Python

Pandas gives you a DataFrame: a table with named columns, like an Excel sheet you control with code. A single column is a Series.

Always start with a first look: head() shows the top rows, shape the size and describe() quick statistics. One bracket df["maths"] gives one column; two brackets df[["name", "maths"]] give a smaller table.

Make new columns with plain maths, filter rows with a condition in brackets, and sort with sort_values(). When you combine conditions, use & and put each condition in its own brackets.

What each line does
df = pd.read_csv("marks.csv")

Reads the file into a DataFrame, a table with named columns. df is the usual name.

df["total"] = df["maths"] + df["science"]

Adds two whole columns row by row and saves the result as a new column called total.

print(df)

Shows the table with the new column.

df[df["maths"] > 70]

The inner part asks True/False for every row. The outer df[...] keeps only the True rows.

[["name", "maths"]]

Two brackets pick a list of columns, giving a smaller table.

df.sort_values("total", ascending=False).head(2)

Sorts from highest total to lowest, then head(2) keeps the top two rows.

Remember

  • One bracket = a column, two brackets = a table.
  • Filters: df[(cond1) & (cond2)], never and.
  • loc selects by label, iloc by position.

05

Real data from a CSV

UPI spends, dates, groupby

One line, pd.read_csv() (or pd.read_excel()), turns a whole file into a table. From there you can ask real money questions: where does my money go?

groupby() answers "for each category, how much?" in one line. value_counts() tells you how often, sum() tells you how much, and they often give different answers: chai is frequent but cheap, rent is rare but huge.

The average can lie when one big payment pulls it up. The median, the middle value, is often the fairer number. Clean messy text with .str.strip() and .str.title(), and save results with to_csv().

What each line does
upi = pd.read_csv("upi_spends.csv", parse_dates=["date"])

Reads three months of UPI payments. parse_dates turns the date column into real dates.

print(upi.shape)

Rows and columns: 104 payments, 4 columns.

upi.groupby("category")["amount"].sum()

For each category, add up the amount. This answers where the money went.

.sort_values(ascending=False).head(4)

Biggest first, and keep the top 4.

upi["paid_to"].value_counts().head(3)

Counts how many payments went to each person or shop. Chai wins on count even though rent wins on money.

upi["amount"].mean() / .median()

The mean (590) is pulled up by rent. The median (60) is the middle payment and describes a typical spend better.

Remember

  • groupby(col)[value].sum() is the most useful line in data work.
  • How often and how much are different questions.
  • Check the median when one value is huge.
